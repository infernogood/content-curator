# ContentCurator

ContentCurator - это Telegram-бот для ведения контентного канала. Он сам собирает
материалы из RSS-лент, отдает их нейросети для перевода и оценки, а потом
присылает вам готовые карточки-черновики. Остается только нажать одну кнопку,
чтобы опубликовать пост в канал.

Бот рассчитан на небольшую команду: несколько пользователей, каждый со своими
источниками, своими настройками и своей очередью модерации.

## Возможности

- Сбор контента из RSS-фидов с подтягиванием картинок (обложки, вложения,
  изображения из HTML-описания).
- Оценка материала нейросетью по шкале от 1 до 10 и автоматический перевод в
  готовый к публикации текст.
- Очередь модерации: черновики, публикация в канал, архив, отклоненные.
- Мультипользовательский режим с заявками на доступ. Новый пользователь попадает
  в очередь, супер-админ одобряет или блокирует его в пару нажатий.
- Раздельные настройки для каждого пользователя: свои источники, свой канал,
  свой порог рейтинга, свой интервал сбора.
- Топ контента по оценке нейросети.
- Работа с любым OpenAI-совместимым API: Gemini, OpenAI, Ollama, vLLM и другими.

## Как это работает

В заданный пользователем промежуток времени бот проверяет источники всех активных пользователей. 
Если источник "созрел", бот читает ленту, берет новые записи и для каждой:

1. Собирает заголовок, описание и картинку.
2. Отправляет текст в нейросеть. Та возвращает рейтинг от 1 до 10 и готовый
   текст поста.
3. Если рейтинг ниже порога заданного пользователем, запись отсеивается.
4. Если рейтинг прошел порог, бот создает черновик и присылает его карточку
   прямо в чат: рейтинг, перевод, оригинал, ссылка на источник.

Вы просматриваете карточки, листаете их кнопками и решаете:
опубликовать в канал, отправить в архив или удалить.

## Установка

Нужен Python 3.10 или новее.

```bash
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux и macOS

pip install -r requirements.txt
```

Затем создайте файл `.env` по образцу `.env.example` и заполните его:

```
BOT_TOKEN=123456
ADMIN_IDS=111111,222222
```

`BOT_TOKEN` - токен бота, который вы получили у @BotFather.
`ADMIN_IDS` - список Telegram ID супер-админов через запятую. Эти пользователи
получают доступ к боту сразу и могут одобрять других пользователей.

## Запуск

```bash
python main.py
```

Остановка - `Ctrl+C`. Логи пишутся в консоль. Уровень логирования задается в
`.env` переменной `LOG_LEVEL` (по умолчанию `INFO`).

## Первое знакомство

1. Напишите боту `/start`. Если ваш ID указан в `ADMIN_IDS`, вы сразу получите
   доступ и пункт меню "Пользователи". Остальные попадут в заявки.
2. В меню "Настройки API" укажите ключ для нейросети (`ai_api_key`). Подойдет любой
   OpenAI-совместимый API. Там же задается ID канала, куда публиковать посты.
3. В меню "Источники" добавьте первую RSS-ленту. Бот попросит ссылку на фид и
   короткое название.
4. Через минуту запустится сбор. Черновики будут приходить в чат по мере
   созревания источников.

## Настройки

Все настройки редактируются прямо в боте, без правки файлов. Значения хранятся в
базе данных, для каждого пользователя отдельно. Если пользователь не задал свое
значение, действует системное.

Основные настройки:

- `ai_api_key` - ключ API нейросети. Отображается в чате в замаскированном виде.
- `ai_base_url` - адрес API, совместимого с OpenAI. Примеры есть в подсказке бота.
- `ai_model_collector` - модель, которая оценивает и переводит контент.
- `target_channel_id` - ID канала для публикации (вида `@mychannel` или
  `-1001234567890`).
- `collector_interval_minutes` - как часто проверять каждый источник.
- `min_rating_threshold` - порог рейтинга. Всё, что ниже, не попадает в черновики.
- `download_user_agent` - User-Agent для скачивания картинок. Часть CDN отдает
  403 без браузерного заголовка, поэтому по умолчанию стоит обычный браузерный.

Отдельно можно менять системный промпт, по которому нейросеть оценивает и
переводит материалы. Промпт находится в меню "Настройки ИИ".

## Команды и сценарии

- `/start` - открыть меню.
- `/help` - краткая справка.
- `/cancel` - выйти из текущего пошагового сценария.

Карточка черновика предлагает три действия: опубликовать, отправить в архив,
удалить. Опубликованный пост уходит в канал, а карточка помечается. Посты из
архива можно вернуть в черновики. Навигация по очередям - кнопками "Пред." и
"След.".

## Структура проекта

```
content-curator/
├── main.py          # точка входа: настройка логов, инициализация БД, запуск
├── config.py        # переменные окружения, константы, системные настройки
├── db.py            # слой работы с SQLite: пользователи, настройки, источники, посты
├── bot.py           # клиент Telegram Bot API, обработчики сообщений и кнопок
├── services.py      # сбор контента, вызов нейросети, пайплайн обработки
├── texts.py         # все тексты и подписи, которые видит пользователь
├── keyboards.py     # разметка клавиатур и кнопок
├── .env.example     # образец файла с настройками
└── requirements.txt # зависимости
```

Данные хранятся в SQLite. Файл базы по умолчанию лежит в `data/content.db`,
скачанные картинки - во временной папке `tmp/`. Пути можно переопределить
переменными `DB_PATH` и `TMP_DIR` в `.env`.

## Модель данных

- `users` - пользователи бота со статусами: `pending` (ждет одобрения),
  `active`, `blocked`.
- `settings` - настройки в виде пар ключ-значение. Запись с `owner_id = NULL`
  задает системное значение по умолчанию, запись с конкретным владельцем
  переопределяет его.
- `sources` - источники пользователей. Сейчас поддерживается тип `rss`.
- `posts` - карточки контента со статусами: `draft` (черновик на модерации),
  `approved` (опубликован), `rejected` (отклонен), `archived` (в архиве).

Данные пользователей изолированы: все операции над источниками и постами
фильтруются по владельцу, а от повторных публикаций защищает уникальный
`dedup_hash` для каждого пользователя.

## Ограничения

- Бот работает синхронно. Пока нейросеть отвечает (обычно 10-30 секунд), новые
  сообщения не обрабатываются. Для личного бота или небольшой команды это не
  заметно, для сотен пользователей потребуется асинхронная версия.
- Telegram накладывает ограничение в 1024 символа на подпись к медиа. Длинные
  переводы при публикации с картинкой обрезаются автоматически.
- Скачивание медиа ограничено 20 МБ на файл.
